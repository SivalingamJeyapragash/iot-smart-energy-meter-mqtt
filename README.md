# IoT-Based Smart Energy Meter Using ESP32 and MQTT

This project implements a smart energy metering system that enables real-time monitoring, automated billing, and remote power control using IoT technologies.

## Features
- Real-time voltage and current monitoring
- Energy consumption calculation (kWh)
- MQTT-based data transmission
- Remote relay ON/OFF control
- Multi-house scalability
- Cloud-ready architecture

## Technologies Used
- ESP32
- MQTT Protocol
- ACS712 Current Sensor
- ZMPT101B Voltage Sensor
- Embedded C / Arduino

## Application
Designed for electricity providers to reduce manual meter reading and improve operational efficiency.
